Favicon generator. Pattern and colour match the logo mark: red, white, red rings with a white bullseye in brand red #E44443, plus the black dart.

    python tools/favicon/export.py <out-dir>

Then copy the PNG/ICO/SVG files (not icon-1024.png or favicon-simple.svg) to the site root. site.webmanifest and browserconfig.xml at the root reference them.
